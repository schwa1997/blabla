# blabla

把对话写成文本，自动生成可以发小红书 / Instagram 的聊天图片（1080×1440，3:4）。

## 怎么用

1. 用浏览器（Chrome / Edge）打开 `index.html`
2. 左边「打开文件夹」选中 `conversations/`，会出现一个聊天记录风格的列表（头像/标题/日期/话题），最新的一篇自动打开
3. 中间默认是「阅读」模式：像读聊天记录一样滚动着看一整篇对话；可以用搜索框按标题/话题/类型/内容/日期过滤左边的列表
4. 切到「导出预览」模式，太长会自动分页成 1080×1440 的卡片；点「导出全部图片」，或点某一页单独导出
5. 中间的文本框可以直接编辑当前打开的对话，改完「保存为 .txt」

导出功能需要联网（会从 jsDelivr 加载 html-to-image）。

## 对话格式

```
title: 和一棵树的对话
topic: 自我评价与存在
type: 哲学
date: 2026-10-08
role: me 🙋‍♀️ 我
role: tree 🌳 树
---
me: 你是不是也有烦恼啊？
tree: 会，但也不会。
```

- `title:` 标题，第一页大标题，后面几页小标题
- `topic:` 这段对话聊的主题，纯元数据，不会出现在导出的图片里，方便整理/检索
- `type:` 对话的类型/目的，比如 `哲学`（偏思辨）、`事实`（科普向）、`闲聊` 等，可以自己定义，同样只是元数据
- `date:` 这段对话发生/发布的日期，用来在左边列表里排序（最新的在最上面）和搜索。不写的话会用文件的最后修改时间代替
- `role: 角色名 头像 显示名`，头像可以是 emoji 或一个字。除了 `me`，其余角色就是这段对话的「partner」——同一个 partner（比如 `tree`）完全可以在好几篇对话里出现，每篇换一个 `topic`/`type`
- `me` 永远在右边，其他角色（partner）在左边
- 没有角色前缀的行，会接到上一句后面换行显示
- `#` 开头的行是注释

对话文件放在 `conversations/` 里，用左边「打开文件夹」整体载入，或用编辑区的「打开 .txt」单独载入一篇。
